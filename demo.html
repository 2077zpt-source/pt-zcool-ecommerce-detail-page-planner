电商详情页策划助手

把产品卖点、用户痛点和素材情况转成可执行的电商详情页结构。

查看 SKILL.md GitHub 仓库

这是做什么的

根据产品品类、价格带、目标用户、核心卖点和证明材料，规划移动端详情页模块顺序、首屏方案、文案层级、视觉重点和素材补拍清单。

适合谁

电商设计师、运营设计师、店铺美工、产品营销人员

详情页电商设计卖点转化页面结构长图策划

典型场景

当你要做电商详情页，但产品资料很散、卖点很多、不知道页面怎么排时使用。

输入什么

产品名称、品类、价格带、目标用户、核心卖点、用户痛点、竞品差异、证明材料、必须展示的参数、素材现状、平台、目标动作

输出什么

页面策略、模块结构、首屏方案、视觉节奏建议、素材补拍清单、合规提醒

使用流程

  1. 1输入产品和卖点
  2. 2判断购买阻力
  3. 3规划详情页模块
  4. 4输出素材补拍清单

示例

输入“便携咖啡保温杯”，输出首屏方向、详情页模块、视觉节奏和合规提醒。
